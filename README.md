# 🌸 Bloom Timer 
> A study timer that's designed to feel more rewarding, it got some cozy and pink vibes to keep you encouraged !
instead of constantly checking the countdown, it keeps breaks surprises !
every completed session you add a small flower to the background 🌷!

## features:
- randomize focus duration
- random encouragement massages!
- focus without countdown
- random break ideas
- notifications for breaks and focus
- calming animations
- and soft pink Bloomed-themed UI

  ## how to use it ?
  1. pick the session duration
  2. start session and lock in! (you can also restart the session if you felt distracted)
